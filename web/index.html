Los 73 libros, carga por libro, tamaño de letra ajustable y cada versículo operable con teclado.

Cómo está hecha

Aplicación web instalable, empaquetada para Android con Capacitor. Sin servidor propio.

Decisiones

  • Biblia en 73 JSON. Se carga un libro cada vez; el servicio guarda en caché y evita peticiones duplicadas.
  • Service worker propio. Caché versionada por compilación; red primero para navegación, caché primero para el resto.
  • Índices en memoria. Parroquias indexadas por código postal, municipio y palabras del nombre, con normalización de acentos.
  • Datos separados del código. Versículos por ánimo como punteros a libro, capítulo y versículo.

Límites conocidos

  • No hay servidor: favoritos y progreso se guardan en el dispositivo.
  • Iglesias está en beta: las posiciones se reparten alrededor del centro del código postal.
  • Solo existe tema oscuro.
  • El buscador cubre libros, oraciones y parroquias, no el texto bíblico.
  • El mapa carga teselas de OpenStreetMap y necesita conexión.

Texto bíblico: Sagrada Biblia, versión oficial de la Conferencia Episcopal Española.
